# 01 · 单元测试用例（UT-*，44 用例）

- 层级：单元测试（类/方法级隔离）
- 手段：JUnit 5 + Mockito（mock repository / FeignClient / JavaMailSender / Environment）
- 隔离边界：进程内，不启动 Spring 容器、不连数据库、不跨服务
- 🔴 = 金融红线用例，失败即阻塞发布，须人工签核
- 关联标注：D=技术债务、R=风险、H=高风险变更、K=已知缺陷（源自 `docs/阶段1-架构审计与升级方案报告.md`）

> 测试代码目录：`<service>/src/test/java/com/piggymetrics/<service>/`，与主代码包路径对齐。

---
