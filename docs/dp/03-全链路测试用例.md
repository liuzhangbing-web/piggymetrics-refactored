# 03 · 全链路测试用例（E2E-*，16 用例）

- 层级：全链路（端到端）测试，跨服务、经网关、真实拓扑
- 手段：docker compose 全栈 + `verify-main-compose.py`(31 断言) / `verify-compensation-e2e.py`(11) / `verify-mongo-real.py`(9) / `integration-test/verify-chain.sh` + 手工 curl
- 环境：Nacos 3.0.3 + Sentinel + MySQL + 4×MongoDB + 5 服务，经 gateway:4000
- 🔴 = 金融红线用例，失败即阻塞发布，须人工签核
