# 02 · 功能测试用例（FT-*，49 用例）

- 层级：功能测试（单服务对外契约：接口、鉴权矩阵、参数校验、业务规则、持久化映射）
- 手段：`@WebMvcTest` + `spring-security-test`（`jwt(...)` 造 token）、`@SpringBootTest` + `@MockBean`、`@DataMongoTest` / 真实 Mongo（`TEST_MONGO_URI`）、Mockito
- 隔离边界：单服务切片，不跨服务调用（Feign 客户端一律 mock）
- 🔴 = 金融红线用例（鉴权等价/金额/越权拦截），失败即阻塞发布，须人工签核
