# 04 · 系统测试用例（SYS-*，15 用例）

- 层级：系统测试（非功能需求：性能 / 韧性 / 可观测 / 安全 / 并发 / 可回滚）
- 手段：压测脚本 + 故障注入 + 观测平台（Jaeger/SkyWalking）+ 多实例编排 + 安全核验
- 环境：全栈容器 + 观测平台叠加编排（`docker-compose.tracing.yml` / `docker-compose.skywalking.yml`）
- 🔴 = 金融红线相关（安全/可追溯），失败即阻塞发布，须人工签核
