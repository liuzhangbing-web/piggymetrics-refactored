# piggymetrics-refactored 测试用例设计文档（阶段3）

- 适用工程：/Users/liuzhangbing/Downloads/D/workspace_tke/piggymetrics-refactored
- 测试框架：JUnit 5 + Spring Boot Test + Mockito + spring-security-test（已在各模块 pom test scope 就位）
- 执行方式（阶段4）：仅 `mvn test`；禁止 drop/truncate 等破坏性数据库操作；Mongo 使用内嵌/Testcontainers 或 mock repository，不连生产数据
- 设计原则：验证"等价迁移"——所有断言以旧工程行为为基准；金额类用例须做数值一致性（黄金数据）对比
- 🔴 标记 = 金融红线用例（账务/金额/鉴权），失败即阻塞发布，结果须人工签核

## 7. 黄金数据录制说明（阶段4前置）

STA-02/EXR-01/CVT 系列需要"旧工程期望值"：在旧工程（Boot 2.0.3/JDK8）对其原有单测夹具运行一次，录制输入输出为 JSON 黄金文件（放 src/test/resources/golden/），新工程断言与其逐值比对。若旧工程无法运行（依赖不可达），则以人工推导值替代并在测试报告中注明。
