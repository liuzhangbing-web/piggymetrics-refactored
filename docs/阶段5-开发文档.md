## 3. 配置体系

### 3.1 加载顺序

1. 本地 `src/main/resources/application.yml`（含 spring.application.name、Nacos 地址、spring.config.import）
2. `spring.config.import: optional:nacos:${spring.application.name}.yml?group=PIGGYMETRICS, optional:nacos:application-common.yml?group=PIGGYMETRICS`
   → 拉取 Nacos 配置（optional 前缀：Nacos 不可达时不阻断启动，便于本地开发与测试）

## 4. 编码规范（本项目约束）

1. **javax → jakarta**：validation/servlet/mail 全部使用 jakarta.*；新增代码禁止引入 javax.validation/javax.mail。
2. **JSON 注解**：仅用 com.fasterxml.jackson.annotation.*（严禁 org.codehaus.jackson，Jackson 1.x 有 CVE）。
3. **校验注解**：@Size（jakarta）替代 hibernate @Length；@Email 用 jakarta.validation.constraints.Email。
4. **Security DSL**：SecurityFilterChain Bean；requestMatchers（非 antMatchers）；@EnableMethodSecurity（非 @EnableGlobalMethodSecurity）。
5. **scope 断言**：@PreAuthorize("hasAuthority('SCOPE_server')")。SAS 默认把 scope 映射为 SCOPE_ 前缀 authority。
6. **Spring 6 Assert**：所有 org.springframework.util.Assert.* 必须显式传消息参数（单参重载已移除）。
7. **Mongo 转换器**：使用 org.bson.Document + @ReadingConverter/@WritingConverter；注册到 MongoCustomConversions。禁止使用 com.mongodb.DBObject（Spring Data Mongo 4 不支持）。
8. **集合工具**：优先 JDK Map.of/List.of/Set.of，不再引入 guava。
9. **MediaType**：APPLICATION_JSON_VALUE（APPLICATION_JSON_UTF8_VALUE 已废弃）。
10. **注入方式**：新增代码建议构造器注入（存量 @Autowired 字段注入保留未改，属 L7 可渐进治理）。
11. **日志**：使用 {} 占位符，禁止字符串拼接用户输入（防日志注入）。
12. **定时任务**：新增 @Scheduled 必须同时加 @SchedulerLock 并给唯一 name。


## 7. 常见坑（实测记录）

| 现象 | 原因 | 解决 |
|---|---|---|
| mvn -T 1C 报 Could not acquire lock(s) | 本地仓库并发文件锁冲突 | 去掉 -T，串行构建 |
| 编译报"程序包 com.fasterxml.jackson.annotate 不存在" | 机械替换 codehaus→fasterxml 时漏了 annotate→annotation | 包名为 com.fasterxml.jackson.annotation |
| 编译报 Assert.hasLength(String) 找不到合适方法 | Spring 6 移除单参重载 | 补消息参数 |
| OAuth2Authorization.fromRegisteredClient 不存在 | SAS API 名为 withRegisteredClient | 用 withRegisteredClient |
| JwtEncoder 找不到符号 | 该类在 org.springframework.security.oauth2.jwt 包，不在 server.authorization.token | 修正 import |
| setJwtCustomizer 类型不兼容 | 需要 OAuth2TokenCustomizer<JwtEncodingContext> 而非 Consumer | 修正类型 |
| shedlock-provider-mongo-jackson:5.16.0 不存在 | 该 artifact 已更名/版本不存在 | 使用 shedlock-provider-mongo + 7.10.1 |
| RSAKey.toRSAPublicKey() 抛 JOSEException 未捕获 | 受检异常 | try/catch 包装 |
| CustomConversions Bean 无效 | Spring Data Mongo 4 使用 MongoCustomConversions | 改 Bean 类型 |
| DBObject 转换器不生效 | Spring Data Mongo 4 不支持 com.mongodb.DBObject | 改 org.bson.Document + @Reading/@WritingConverter |
